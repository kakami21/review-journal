# ボイスメモをブログ記事にするとき

編集の強さは「弱」を基本とする。

- 話した順番と本人の言い回しを残す。繰り返しや言い直しにも、その場で考えた跡や感情が出ていれば残す。
- 脱線した話もその位置に残す。話していない説明や結論、文学的な描写を足さない。
- 明らかな誤字や音声認識の誤りを直す。「あの」「えっと」などは、取っても言葉の調子が変わらないところだけ省く。
- 録音の途中で「この字は〇〇の〇ね」などと表記を指定したら、該当する語にその表記を使う。文字起こしに向けた補足は本文から省く。
- 読みやすい位置に句読点と改行を入れる。記事本文の段落間に空白行は入れない。

## 編集例（説明用の作例）

編集前：「えっと、昨日さ、本屋に寄ったんだよね。なんとなく。いや、なんとなくっていうか、あの、帰るにはちょっと早かったんだよね」

編集後：「昨日さ、本屋に寄ったんだよね。なんとなく。いや、なんとなくっていうか、帰るにはちょっと早かったんだよね。」

編集前：「広げていける。この広げるは拡散方程式の拡ね」

編集後：「拡げていける。」
