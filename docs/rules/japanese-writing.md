# 日本語の文章

チケットのタイトル・本文を日本語で作成・更新するときと、ユーザーへの最終回答を日本語で書くときは、`natural-japanese` スキルを必ず使用する。文章を作る前にスキルの指示を読み、生成した日本語を自然で読みやすい表現に整えてから出す。

チケットの項目は[チケットの書き方](ticket-writing.md)と導入先の管理ツールに従う。スキルによる推敲で、事実や確認結果を変えない。

## 参考資料

- [英国教育省のプレーンランゲージの指針](https://design.education.gov.uk/content-design/plain-language)：読み手に合う語彙、短い文、内容を探しやすい構成を考える際の参考資料。

参照先は英語の文章に関する指針であり、日本語の表記規格ではない。`natural-japanese`スキルの使用と適用範囲は、このリポジトリ独自の運用とする。
