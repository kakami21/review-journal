# Tasks

## 1. トップページの表示と登録手順

- [ ] 1.1 `src/pages/index.astro` に `WidgetArea` を読み込み、本文コンテナーの投稿セクションより前に `home-author-profile` を配置する。配置が投稿件数に依存せず、共通レイアウトや他ページには追加されていないことを差分で確認する。
- [ ] 1.2 `src/styles/global.css` に専用クラス内のカード・見出し・本文・円形アイコンのスタイルを追加する。自己紹介の外に装飾が及ばず、画像がない場合も文章を読めることを画面で確認する。
- [ ] 1.3 `docs/setup.md` に環境の確認、エリアの識別名・表示名、コンテンツブロック一つへの画像・名前・紹介文の登録、編集・画像差し替え・取り外しの手順を追記する。専用の入力欄があると誤解しない説明になっていることと、コード側の識別名との一致を確認する。

## 2. 表示と管理画面の連携確認

- [ ] 2.1 `npm test`、`npm run build:preview`、`npm run build:production` を実行し、既存テスト・型チェック・両環境のビルドが成功することを確認する。コマンドと結果を作業記録に残す。
- [ ] 2.2 previewを対象に、エリア未作成、エリア作成後のウィジェット未登録、自己紹介一つの登録の順で表示を確認する。未登録時に空の見出し・カード・専用の余白がなく、登録後は紹介文と投稿一覧の間に表示されることを記録する。既存の登録がある場合は保存内容を控え、無断で削除して検証しない。
- [ ] 2.3 previewの管理画面で名前・紹介文の更新、画像の差し替え・取り外し、ウィジェットの取り外しを確認する。サイトの再ビルドなしで再読み込みに反映され、代替テキストが出力され、画像なしでも文章が残り、ウィジェットを取り外すとカードが消えることを記録する。確認後は使用した内容を元に戻す。
- [ ] 2.4 375pxと1280pxで短い文と長い文を表示し、円形アイコン・折り返し・横スクロールの有無を確認する。`/reviews`、存在する個別記事、存在しない投稿のページには自己紹介が表示されないことと、既存の投稿の表示順・リンクが保たれていることを記録する。

## Workflow follow-up

- 文書の内容を確認してから、この変更を指定して実装を開始する。
- 実装と動作確認後、プロジェクトの手順に従って完了した変更をアーカイブする。
- 本番公開が必要な場合は `docs/deploy-production.md` に従い、公開する変更・復旧方法・本番管理画面での登録内容を確認してから別途実施する。
