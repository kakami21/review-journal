# Proposal

## Why

今のトップページには記事・ノート・口コミの一覧があるが、書き手を紹介する場所がない。初めて訪れた人が誰の日記か分かるように、EmDashの管理画面から更新できる自己紹介欄を追加する。

## What Changes

- トップページのサイト紹介文の下、投稿一覧の前に「この日記を書いている人」を表示する。
- アイコン画像・名前・短い自己紹介を、EmDash標準のコンテンツブロックで編集する。
- トップページ専用のウィジェットエリア `home-author-profile` を使用する。表示場所と見た目はサイト側で決める。
- 現在の背景色・カードの枠線・影・本文幅に合わせ、スマートフォンでも読める大きさにする。
- エリアが未作成、またはウィジェットが未登録なら、自己紹介欄を表示しない。
- 管理画面での登録・更新方法と、検証環境での確認方法を導入手順に追加する。

## Capabilities

### New Capabilities

- `author-profile-widget`: トップページに書き手の自己紹介を表示し、その内容をEmDashの管理画面から更新できる。

### Modified Capabilities

なし。

## Impact

- `src/pages/index.astro`: トップページに標準の `WidgetArea` を配置する。
- `src/styles/global.css`: 自己紹介エリアの中だけに適用するスタイルを追加する。
- `docs/setup.md`: エリアの識別名と、画像・名前・紹介文の登録手順を追加する。
- 既存のEmDash 1.3.1とメディア保存先を利用する。新しい依存関係・DBマイグレーション・独自プラグインは追加しない。
- 共通レイアウトへの配置、個別記事・一覧ページへの表示、SNSリンク、複数著者への対応は今回の範囲に含めない。
- この提案の作成ではコード・CMSの実データ・公開環境を変更しない。
